# 🤖 ANDROID — GOOGLE PLAY

This file is ONLY for the Android release of BuildFlow HQ.

## Build the Android app
```bash
npm install
npm run mobile:add:android
npm run mobile:sync
npm run mobile:open:android
```

## Open in
Android Studio.

## Store destination
Google Play Store / Google Play Console.

## App identity
- Name: BuildFlow HQ
- Application ID: `com.buildflowhq.app`
- Platform: Android

## Release output
Create a signed Android App Bundle (`.aab`) in Android Studio and upload it to Google Play Console.

## What is still required from the owner
- Google Play Console developer account
- Android app signing setup
- Store listing details
- Screenshots and privacy information

Do not store Android keystores, signing keys, or passwords in GitHub.
